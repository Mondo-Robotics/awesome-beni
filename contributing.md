# Contribution Guidelines

One repository, one line. Keep it short.

## What belongs here

- A Beni-related open-source project with a public repository and a real license.
- Nothing that is only a landing page, a closed beta, or a duplicate of an existing entry.

## Format

```markdown
- [Repository](https://github.com/owner/repo) - One sentence on what it does.
```

- Capital first letter, period at the end, one line.
- Link the repository itself, without a trailing slash.
- Put the entry in the projects list, in the order that reads best.
- Only link documentation inside a repository if the repository itself does not already cover it.

## Before you open a pull request

1. Check that the link resolves and the project still works.
2. Search the readme for the name and the URL to avoid duplicates.
3. Run `npx awesome-lint`. CI runs the same check.

By participating you agree to follow the [code of conduct](code-of-conduct.md). All contributions are released under [CC0 1.0](license).
